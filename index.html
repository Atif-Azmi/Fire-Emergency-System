3. TRILATERATION vs FINGERPRINTING COMPARISON

Log-Distance Path Loss

Trilateration (Geometry-Based)

$$\text{RSSI} = \text{RSSI}_0 - 10n \log_{10}(d)$$

$$d = 10^{\frac{\text{RSSI}_0 - \text{RSSI}}{10n}}$$

  • Weakness indoors: Path loss exponent $n$ varies unpredictably through walls ($n=2.0$ to $4.5$).
  • Error margin: $10\text{--}15\text{ meters}$ (circles do not intersect cleanly).

Fingerprinting (Pattern-Matching) — Adopted Solution

Matches live multi-AP signal vector directly against surveyed physical building database.

  • Strength indoors: Wall attenuation and multipath reflections are already baked into the data.
  • Error margin: $3\text{--}8\text{ meters}$ (accurate to room/quadrant level).
